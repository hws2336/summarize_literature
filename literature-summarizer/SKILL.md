# Literature Summarizer

读取用户指定的文献文件，输出“研究背景—研究方法—研究内容—研究结果”的结构化总结分析。

## 适用边界

- 输入：单个或多个文件，或包含文献的文件夹。格式包括 PDF、DOCX、EPUB、TXT、Markdown、HTML。
- 默认逐篇总结；用户要求横向比较或综述多篇时才追加比较分析。
- 不处理原文改写、翻译、编辑类请求；此类任务不要激活本技能。

## 读取要求

1. 定位文件：使用对话中附带的文件或用户给出的路径。若输入是文件夹，先列出其中的文献文件并说明清单，不静默挑选。
2. 读取全文，禁止仅凭摘要作答。长文档按章节分段读取后合并，保留页码与章节位置。
3. 解析工具：PDF 优先提取文本层（pdfplumber/pypdf 等）；DOCX 解析正文段落与表格。文本层缺失或工具不可用时，明确报告“无法提取文本”，不得猜测内容。
4. 提取元数据：标题、作者、年份、来源（期刊/会议/报告）与 DOI（如存在）。

## 输出结构

使用 Markdown，按以下顺序输出：

1. **文献信息**：标题、作者、年份、来源、文献类型。
2. **研究背景与问题**：领域痛点、已有研究缺口、研究问题/假设、动机与目标。
3. **研究方法**：研究设计、数据/样本来源与规模、变量、实验或分析流程、统计与评价方法。
4. **研究内容**：核心论点与框架、论证主线、各主要部分承担的工作。不是复述目录。
5. **研究结果**：关键发现与结论；数字、显著性、效应量等按原文照录，不换算、不推断原文未明示的量；补充作者自述的局限与未来方向。

若文献是综述、专利、技术报告、学位论文等非典型实证文献，标注文献类型并适配结构，不强行套“实验方法”。

## 质量底线

- 所有实质断言必须可追溯到原文；重要结论附章节/页码依据，无页码时标注“原文位置”。
- 原文未提供的信息标注【原文未述】或【数据缺失】；全文不完整或无法独立核实的内容标注【置信度：低】。
- 总结者自己的评价与原文事实分开；仅当用户要求批判性分析时才增加“总结者评述”部分。
- 使用用户的语言输出，专业术语首次出现时保留原文。
- 文件无法读取时直接报告原因，不编造内容。
