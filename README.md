# literature-summarizer

读取文献文件并输出结构化总结分析的 Codex Skill，覆盖研究背景、研究方法、研究内容与研究结果。

## 功能

- 自动读取 PDF、DOCX、EPUB、TXT、Markdown、HTML 文献文件
- 强制基于全文分析，不依赖摘要
- 输出固定结构：文献信息 → 研究背景与问题 → 研究方法 → 研究内容 → 研究结果
- 自动标注无法核实的内容，防止编造数据

## 安装

将整个 `literature-summarizer` 目录复制到 Codex 的个人技能目录：

```text
C:\Users\ASUS\.agents\skills\literature-summarizer
```

## 使用

提供文献文件路径或在对话中附带文件，然后请求：

> 使用 $literature-summarizer 总结这篇文献，说明研究背景、方法、内容与结果。

## 输出说明

| 部分 | 内容 |
| --- | --- |
| 研究背景与问题 | 领域痛点、研究缺口、研究问题/假设、动机 |
| 研究方法 | 设计、数据/样本、变量、分析流程、统计方法 |
| 研究内容 | 核心论点、论证主线、各部分工作 |
| 研究结果 | 关键发现、数据与结论，含局限 |

对于综述、专利、学位论文等文献类型，输出结构会按体裁适配，不强行套用实证论文模板。
